# 星愿圣诞树

一个手机优先的交互圣诞树网页。粉白粒子树悬浮在纯星空中，每颗白色小球固定承载一条祝福。单指旋转、双指缩放，访客无需登录即可留下祝福。

## 功能

- Three.js实时3D粒子树、螺旋光带、星尘光环与白色球形挂饰。
- 简约线条界面，留言表单、昵称列表、祝福详情及树上定位。
- 昵称选填，祝福最多200字，提交后公开，同一浏览器可修改或删除自己的留言。
- 独立管理后台，查看昵称、祝福和时间，支持删除。
- SQLite共享留言与版本同步，背景音乐及静音开关。

设计基准在design/previews/，完整交接见[项目说明与交接.md](./项目说明与交接.md)。当前已有本地实现和自动化检查；实际微信设备兼容性仍需验收。

## 本地运行

需要Node.js 24.16+，建议使用Node 24 LTS。保留锁文件，通过npm ci安装。

```sh
npm ci
npm run dev
```

开发页面为http://localhost:5173，管理页面为/admin。

```sh
npm run build
npm start
```

构建后由Node提供完整网页。运行参数见.env.example，将实际配置保存为.env，不要提交密码或真实环境信息。管理后台没有默认密码，通过npm run admin:password生成本机配置。音乐资源随项目一起提供，构建时会复制到静态输出目录。

## 检查

```sh
npm run build
npm test
npm run test:browser
```

浏览器检查使用本机Chrome，非默认路径可设置CHROME_PATH。测试在隔离数据库中运行，不会添加示例留言到真实数据。截图与结果保存到忽略的artifacts/目录。桌面浏览器的手机尺寸模拟不代表真机微信验收。

## 部署与更新

服务器从本仓库拉取源码后，需要安装依赖、构建、设置独立运行服务与访问入口。Git仓库同步不会自动替服务器部署或重启。

deploy/提供通用Nginx和systemd示例，其中的域名、目录和用户均为占位配置，使用前必须按实际环境调整。先核实已有站点和端口；新项目使用独立目录与服务，保留其他项目。流程见[服务器接入步骤](./deploy/服务器接入步骤.md)。本仓库不包含真实服务器地址或访问凭据。

留言数据保存在服务器本地数据库中，不随Git覆盖。备份命令：

```sh
node --env-file-if-exists=.env scripts/backup.mjs
```

更新前先备份，完成构建与检查后再重启本项目服务。域名、HTTPS和微信访问需在真实部署环境中验证。
